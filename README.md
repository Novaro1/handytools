# HandyTools

**15 free online developer & productivity tools with a Windows‑95 interface — no signup, no ads, no tracking.**

🔗 **Live site: [handytools.dev](https://handytools.dev)**

Every tool runs entirely in your browser. Nothing is uploaded to a server, so it's safe for sensitive data.

## Features

- **100% client‑side** — all processing happens in your browser; no data leaves your machine
- **Retro Windows‑95 UI** — beveled buttons, title bars, tree navigation, a working taskbar
- **Zero dependencies** — vanilla HTML, CSS, and JavaScript; no build framework, no npm
- **Fast & light** — shared `styles.css` + `app.js`, served from a global CDN
- **Mobile responsive** and fully keyboard navigable

## Project structure

```
build.py         # generator: turns the single-page app into per-tool SEO pages
_source.html     # source of truth (the single-page app)
public/          # generated static site (this is what gets deployed)
  index.html
  <tool>.html    # one SEO-optimized page per tool
  styles.css
  app.js
  favicon.svg / favicon.ico
  sitemap.xml / robots.txt / 404.html
```

## Build

The site is generated from `_source.html` by a small Python script — no dependencies beyond Python 3:

```bash
python3 build.py      # regenerates everything into public/
```

Then serve `public/` with any static file server:

```bash
cd public && python3 -m http.server 8000
```

## Tech

Vanilla HTML/CSS/JS, generated by a ~300‑line Python build script, hosted on Cloudflare Pages.
